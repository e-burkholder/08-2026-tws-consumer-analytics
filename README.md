## Objectives
This project aims to analyze how consumers interact with TWS across streaming platforms, social media, goods/merchandise, and other touchpoints. 

I aim to discover:
1. Who is the current audience?
2. How do consumers discover and engage with TWS?
3. Which markets are demonstrating growth?
4. What behaviors correlate with high engagement or purchasing?
5. Which consumer segment offers the greatest opportunity?
6. How could this information be utilized to improve marketing efforts?
7. How could future comeback marketing campaigns better target this audience?
